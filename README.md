# NOVA-APEX

The active computer-use agent application is in the agent/ directory.

Start with the [NOVA-APEX application guide](agent/README.md) for requirements, safe setup, local Mission Control, configuration, tests, and security notes.

This Git repository currently contains other historical experiments and archived files at its root. The hardening change set is intentionally scoped to the NOVA-APEX application and does not remove unrelated top-level material. A separate repository-cleanup pass should review those files and Git history with the owner before deleting or rewriting anything.
